# Política de seguridad

La seguridad de AniVexa y de las personas que lo usan es importante.

## Versiones con soporte

Se aceptan reportes para la versión estable más reciente. No se garantiza soporte de seguridad para versiones anteriores.

## Reportar una vulnerabilidad

- Usa la opción **Report a vulnerability** de la pestaña **Security** de GitHub para enviar un reporte privado: [reportar una vulnerabilidad](https://github.com/dfedez920912/AniVexa/security/advisories/new).
- Si el reporte privado no está disponible, no publiques detalles de explotación, datos personales ni información sensible en un issue. Contacta en privado a las personas mantenedoras a través de [su perfil de GitHub](https://github.com/dfedez920912) para acordar un canal seguro.
- Incluye, cuando sea posible, la versión afectada, el impacto, los pasos para reproducir el problema y una mitigación sugerida. No adjuntes credenciales ni datos de terceros.

Se confirmará la recepción cuando sea posible y se coordinará la divulgación con quien reportó el problema. No abras un issue público para una vulnerabilidad no corregida.
